Goal: Build a four-card editorial resource grid for a modern product page.
Structure: resource type label, original abstract thumbnail, heading, description, CTA.
Motion: stagger reveal on entry and a restrained thumbnail zoom on hover/focus.
Responsive: 4 columns wide, 2 tablet, 1 mobile.
Accessibility: semantic articles, focus-visible CTAs, reduced-motion fallback.
Constraints: no external images or libraries.
