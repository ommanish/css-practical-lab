Vibe Coding Prompt

Copy this structure and interaction spec into your coding assistant.

Goal: Create a horizontal customer-story gallery using native scroll snap.
Structure: editorial section header with previous/next controls, followed by at least four large story cards with original abstract artwork and metrics.
Interaction: native touch, mouse, and trackpad scrolling remain primary; buttons scroll one card at a time.
Motion: active movement comes from native smooth scrolling; card hover/focus uses subtle translate and media scale.
Responsive: show one full card plus a hint of the next on mobile; 2–3 cards visible on desktop.
Accessibility: labeled buttons, visible focus, controls do not trap keyboard users, reduced-motion disables smooth scrolling.
Constraints: minimal vanilla JS, no carousel library.
