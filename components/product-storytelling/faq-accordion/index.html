Goal: Build an accessible FAQ accordion with five or more questions.
Structure: real button in each question row, answer region below, fixed circular icon container.
Interaction: toggle aria-expanded and animate answer height using CSS grid 0fr to 1fr.
Icon: draw plus/minus strokes with ::before and ::after; never rotate or resize the circle itself.
Responsive: keep question text and icon aligned at 320px.
Accessibility: keyboard-native buttons, labelled regions, visible focus, reduced-motion fallback.
Constraints: minimal vanilla JS and no accordion library.
