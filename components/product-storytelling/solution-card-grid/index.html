AI build prompt

Vibe Coding Prompt

Use this prompt in your coding assistant, then adapt the visual language to your product.

Goal: Create a responsive six-card solution grid for an enterprise product page.
Visual structure: section intro followed by six large cards; every card contains abstract artwork, eyebrow, heading, description, and CTA.
Motion: cards reveal with subtle stagger; artwork scales or shifts slightly on hover/focus; CTA arrow moves 4px.
Responsive: 3 columns on large screens, 2 on tablet, 1 on mobile.
Accessibility: semantic articles, visible focus states, no hover-only information, reduced-motion fallback.
Constraints: original CSS/SVG-style artwork only, no libraries, no external images.
