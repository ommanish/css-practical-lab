Prompt

Create an experimental but practical spotlight mosaic grid for a modern portfolio or product page. Use an asymmetric CSS Grid with a mix of wide, tall, and compact tiles. Each tile should include an index, short category label, headline, supporting copy, and an abstract CSS-generated visual so no canvas or WebGL is required.

Make the core interaction CSS-first. Use custom properties for pointer coordinates, radial gradients or masks for the spotlight, and perspective transforms for a very subtle tilt. Add only a tiny vanilla JavaScript helper that converts pointer position into CSS custom properties. Hover and keyboard focus must reveal the same supporting content.

Keep the layout stable while the spotlight moves. On touch or coarse-pointer devices, disable tilt and show all important copy without requiring interaction. Respect prefers-reduced-motion, provide strong focus-visible states, and ensure the grid remains useful with JavaScript disabled.
