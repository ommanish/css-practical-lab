Build this interaction

Prompt

Create a sophisticated perspective card stack for a product or editorial story. Use four large full-width cards with strong typography, restrained visual motifs, rounded corners, and distinct background tones. The cards should remain readable and well composed before any JavaScript runs.

Use CSS position: sticky as the base interaction. On desktop, enhance the stack with GSAP and ScrollTrigger so that when the next card arrives, the previous card recedes slightly using a small scale reduction, a subtle upward shift, a very light perspective rotation, and a gentle opacity change. Keep the effect refined and avoid dramatic 3D movement. Each card should remain visible long enough to read before the next handoff begins.

Do not hijack scrolling. On mobile, remove the sticky choreography and display the cards as a normal vertical sequence with compact spacing. Respect prefers-reduced-motion by disabling transform-based enhancement. Preserve semantic article order, visible focus states, and complete content when JavaScript or GSAP is unavailable.
