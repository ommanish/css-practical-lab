Build this interaction

Prompt

Create a sophisticated orbital story timeline for a product or systems narrative. Use a two-column desktop layout: changing chapter copy on the left and one persistent orbital diagram on the right. Build the orbit with SVG/CSS, including an outer path, inner reference ring, four numbered nodes, a central state indicator, and a small marker that travels on the orbit path without covering the node labels.

Create four scroll states: Detect, Connect, Decide, and Act. As the user scrolls through a pinned desktop scene, show only the active chapter, highlight its matching node, update the center value from 01 to 04, and move the marker smoothly to the corresponding direction on the outer orbit. Calculate marker positions from the real orbit geometry so the motion remains aligned at different responsive sizes. Use GSAP and ScrollTrigger for synchronization, but keep the motion restrained and readable.

Do not use scroll hijacking. The marker must remain visually separate from the numbered node circles. On mobile and for prefers-reduced-motion, remove pinning and display all chapters in normal vertical flow with the orbit as a static visual. Keep the content complete when JavaScript or GSAP is unavailable and preserve accessible document structure.
