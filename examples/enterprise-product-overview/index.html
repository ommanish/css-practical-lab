Vibe Coding Prompt

Recreate the storytelling architecture with your own brand, product, and content.

Goal: Create a premium, original enterprise product overview page using a reusable component system.
Structure: announcement, two-column hero, six solution cards, accessible capability tabs, four numbered features, continuous trust marquee, scroll-snap customer stories, two editorial proof cards, one oversized community/promo blade, four integration cards, four resource cards, two-up conversion CTA, and FAQ.
Visual behavior: alternate deep-ink and warm-off-white sections, oversized editorial typography, abstract CSS/SVG-style artwork, generous spacing, rounded media surfaces, lime primary accent with violet/cyan secondary accents.
Motion: CSS-first staggered reveals, ambient hero movement, tab crossfade/clip transition, marquee, scroll-snap, subtle card hover transforms, FAQ grid reveal. Use View Transition API only as progressive enhancement.
Responsive: no horizontal page overflow from 320px upward; grids collapse 4→2→1 and 3→2→1; hero/promo stack below tablet widths.
Accessibility: keyboard tabs, labelled gallery controls, aria-expanded FAQ buttons, visible focus, semantic headings, reduced-motion fallback.
Constraints: no framework, build tool, animation library, external brand assets, copied marketing copy, or third-party imagery.
